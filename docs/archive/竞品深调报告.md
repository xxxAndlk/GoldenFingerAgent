# 市场与竞品深调报告

> 调研时间：2026-10-03
> 目的：回答"现有 App 是否已覆盖本项目想做的事"，找到结构性缝隙，修正产品定位。
> 方法：桌面研究（公开报道、官网、应用商店、行业报告）。结论需在第 0 阶段用真实家庭访谈验证。

## 二、五类玩家情报卡

### 1）AI 老人陪伴：硬件走红、纯软件被监管打压

- **ElliQ**（以色列 Intuition Robotics）：陪伴机器人标杆。主动发起互动（日均 30+ 次）、情感陪伴 + 健康提醒，美国多州政府试点，累计融资约 8500 万美元，进入日本。卖点是"主动陪伴"而非功能。
- **国内 2026 年关键政策变化（7·15 新规前后）**：豆包、千问的拟人智能体下线；猫箱、星野等情感陪伴 App 承压；**实体养老机器人反而拿到"合规门票"**——如身机器人亿元级 Pre-A、优必选 U1 爆单 1.3 万台，主打医疗/照护属性。
- 廉价替代：淘宝上搭载豆包/DeepSeek/小度的音箱 198 元起。

**启示：**
- "虚拟亲人/赛博儿女"路线在国内有明确监管风险，**本项目绝不能定位成拟人陪伴**。
- "功能工具 + 安全照护"是合规安全区。
- 纯软件做陪伴打不过硬件机器人和廉价音箱。

### 2）家庭守护/远程协助：厂商全做了，但有一堵"品牌墙"

- **Amazon Alexa Together**（订阅约 $19.99/月）：活动流、无活动告警、Remote Assist（子女远程设提醒/清单）、Circle of Support（最多 10 位看护人）、24/7 紧急响应。需 Echo 硬件。
- **国内厂商（2026 年均已到位）**：
  - 华为：远程守护长辈（家长助手扫码绑定）、亲情防诈（风险实时通知子女 + **远程挂断**）
  - 荣耀：家庭空间 / 远程守护
  - vivo：家人共享（位置共享、远程协助、安全事件提醒）
  - 小米：家人服务
- **共同的硬限制**：
  1. **只支持自家品牌手机之间互连**——老人华为、子女小米/iPhone 是现实中的大多数组合，直接失效；
  2. 每次远程连接需老人当场点"同意"；
  3. 行业曾出现远程协助功能集体下架潮（隐私与责任顾虑）。

**启示：跨品牌，是最大的、被结构性保留下来的缝隙。**

### 3）反诈拦截：厂商系统级已很强，但防线还停在"电话里"

- 系统级能力（2026）：华为 AI 变声检测 + 诈骗话术检测（含三方通话）、vivo 大模型通话分析、红米、Google Pixel 诈骗检测；新机型已支持"子女远程收到风险通知 + 远程挂断"。
- App 级：国家反诈中心（官方身份、号码库强）；WHO AI 等第三方评分低（3.4 分）。
- **但诈骗形态已经迁移**（新华网 2025-10 深度报道）：
  - 假"精准扶贫/AI 任务"App、假投资平台（后台篡改卡号、伪造收益）；
  - 微信群/视频会议"培训"长期洗脑，话术包括**"子女阻碍你赚钱""这样的儿子会给你养老吗"**——主动离间老人与子女；
  - 屏幕共享、套取验证码；老人隐瞒子女长达数月，有被骗超 100 万的案例；
  - 子女的真实对抗手段极其原始：偷拿手机举报、登录账号拉黑骗子、没收手机（老人随后自行买新机）。

**启示：**
- 通话反诈不要碰——系统级能力免费且更强。
- **"App 内 / 屏幕内的诈骗剧本"是无人防守的地带**：系统厂商有商业包袱不能监控第三方 App 内容，国家反诈 App 看不见屏幕里正在发生什么。这正是无障碍能力的用武之地。

### 4）用药管理：工具成熟，但没有"语音医嘱 + 家庭闭环"

- **Medisafe**：全球 1300 万+ 用户，可视化药盒、库存管理、家人共享——但仍是"手动配置的提醒工具"。
- **MyTherapy**：用药 + 症状记录 + 给医生的健康报告，欧洲强。
- 国内无强势独立用药 App。
- 共同空白：**看完病口述医嘱自动转用药计划 → 确认"吃了" → 漏服升级子女 → 周报**，无人做成语音优先的闭环。

### 5）医疗 Ambient AI：技术已被验证，但只服务医院

- **Abridge**：医患对话实时转结构化病历，估值 53 亿美元，部署 150 家医疗系统（梅奥、杜克等），2026 年仍在高速增长。
- 它是 toB（给医生写病历），**"老人看完病自己录一遍医嘱、自动转成提醒"的 C 端家庭版无人做**。技术可行性已被它证明。

## 四、三个结构性事实（本次调研最重要的结论）

1. **品牌墙 = 护城河级缝隙**：最强的家庭守护能力全在手机厂商手里，但只在同品牌生态内生效。跨品牌的家庭安全纽带，没有占位者。
2. **骗子已从"电话里"搬到"屏幕里/App 里"，而防线没跟上**：系统反诈管通话，管不到假 App、群内洗脑、屏幕共享的行为链。这需要跨 App 观察能力（无障碍），厂商出于商业包袱不做。
3. **"拟人陪伴"路线被监管证伪，"工具/安全"路线合规且真空**：本项目要做的是安全设施，不是虚拟亲人。

| 威胁 | 说明 | 应对 |
|---|---|---|
| 窗口期可能只有 1–2 年 | 厂商已做到"子女通知+远程挂断"，若未来推出跨品牌互联（行业已有倡议），缝隙会收窄 | 速度优先；趁窗口期积累真实事故案例和家庭关系数据 |

## 七、三钉子的修正（避让强势区，押真空区）

### 钉子 1：屏幕内诈骗守卫（原"转账拦截"升级）

- **不做**：通话反诈（系统级已免费且更强）。
- **做**：识别 App 内/屏幕内的危险行为链——
  - 假投资/假任务 App 特征 + 收益/提现话术；
  - 屏幕共享开启 + 银行/支付 App 同时在前台；
  - 索要验证码、"安全账户"、离间子女的话术；
  - 长时间"会议/培训"式洗脑。
- **动作**：大字全屏"先停一下" → 三行大白话 → **跨品牌通知子女**（子女任何品牌手机、甚至 iPhone 都能收到）→ 老人一键放行，拦截记录留档。
- 这是"系统厂商不做、国家反诈 App 做不到"的原理性位置。

### 钉子 2：吃药流程卡片（Abridge 的家庭版）

- 看病回来，老人**口述一遍医嘱**（或子女远程录入）→ 自动生成用药计划 → 写系统闹钟保证触达 → 语音/点按确认"吃了" → 漏服 30 分钟升级子女 → 周报到子女端。
- 核心差异：**确认 + 漏服升级 + 周报**，且跨品牌可见。Medisafe 们只做提醒工具。

### 钉子 3：子女端跨品牌看板

- **优先微信服务号/小程序**（子女无需装 App、不挑手机品牌；模板消息即通知），而非独立 App。
- 默认只显示结构化事件（隐私三级模型不变）；两个动作：提议代办（老人大字确认）、紧急时请求查看（24h 限时授权）。
- "跨品牌"本身就是卖点：**"看得见安危，看不见隐私，还不挑手机牌子。"**

### 低成本高感知配菜

- 来电关系浮层：张阿姨来电时浮出"女儿在广州，上次聊到她腰不好"。

## 八、对 90 天计划的调整

1. **第 0 阶段（2 周）需求验证追加两个必问项**：
   - 访谈必问："你和父母的手机各是什么品牌？"——验证跨品牌家庭占比（缝隙是否够大）；
   - 假门海报主文案改为"**你和爸妈手机牌子不一样，也能拦住他转账**"，对比旧文案测点击意向。
2. **守卫切片的开发内容从"转账页拦截"改为"行为链检测"**（屏幕共享+支付前台、验证码、假 App 特征三规则先行，LLM 语义兜底）。
3. **子女端技术选型定为微信服务号/小程序先行**，不做独立 App，节省一人业余项目的宝贵精力。
4. 北极星指标不变：每周"被产品接住的真实事故数"；新增过程指标：跨品牌家庭占比、守卫触发场景分布（验证骗子是否真在屏幕里）。
5. 工程线（CI、拆 tools_impl.go、embedder 降级提示）照旧穿插，不挡主线。

## 九、待验证假设（第 0 阶段收口）

- [ ] 跨品牌家庭（父母与子女主力手机不同品牌）占比是否 ≥60%？
- [ ] 子女是否愿意为"跨品牌安全纽带"付费/留资？
- [ ] 屏幕内诈骗行为链在真实老人手机上的出现频率（人工后台实验记录）？
- [ ] 无障碍在小米/华为真机上观察第三方 App 内容的技术稳定性与审核口径？
- [ ] 老人对"口述医嘱自动转提醒"的接受度？

---

**一句话总结**：厂商用"品牌墙"把家庭守护圈在各自生态里，骗子从电话搬进了 App 里——这两件没人管的事，正好是本项目唯一原理性的位置：**不挑品牌的家庭安全纽带**。窗口约 1–2 年，速度和真实事故案例是唯一的壁垒。
